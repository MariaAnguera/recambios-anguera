# 🚗 Recambios Anguera

Sitio web e-commerce y catálogo interactivo enfocado en la venta de recambios y accesorios para automoción. Proyecto desarrollado con un enfoque modular, estructurado para ofrecer una experiencia de usuario intuitiva en la búsqueda de piezas de coche.

## 🚀 Características principales
* **Catálogo de Productos:** Visualización organizada de recambios con fichas detalladas y tarjetas de producto optimizadas.
* **Sección de Contacto y Formularios:** Formulario de atención al cliente con validación en HTML para consultas sobre piezas específicas.
* **Navegación Optimizada:** Enlaces y tarjetas configurados para una navegación fluida entre secciones y apertura de detalles.
* **Diseño Responsive:** Interfaz adaptada a diferentes dispositivos para asegurar la accesibilidad móvil y de escritorio.

## 🛠️ Tecnologías utilizadas
* HTML5 / Semántica web
* CSS3 / Estilos personalizados
* Bootstrap (para componentes de diseño y maquetación rápida)
* JavaScript (para interactividad de elementos y comportamiento de enlaces)
